About the data How contribution counts and tile sizes work

Data comes from the public GitHub API. We show up to 100 contributors, ranked by commits attributed by GitHub. This is not a measure of code quality or a complete record of reviews, issues, or other work. GitHub caches contributor statistics, so recent commits may take time to appear.

Treemap areas use square-root weighting to keep smaller contributors visible. On small screens, use the list view for easier selection. Hover or focus a tile for rank and contribution count; select a contributor for their profile and share link. Portfolio links come from the public website field on their GitHub profile.

SVG, PNG, and JPEG exports include the currently loaded contributors. Use PDF and select “Save as PDF” in your browser. Avatars are embedded when available; a labeled tile is used if an avatar cannot be downloaded. Share links reopen the selected repository and highlight the contributor. Public API rate limits are shared with other requests from your network; retry later if the limit is reached. No GitHub token is required or stored.
